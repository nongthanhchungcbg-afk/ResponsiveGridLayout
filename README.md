# Bố cục responsive bằng CSS Grid

Trang mẫu có header, navigation, nội dung chính, sidebar và footer. Grid Areas sắp xếp phần khung; trên desktop main có nội dung chính cùng sidebar, còn dưới 650px tất cả khu vực chuyển sang một cột.

## Chạy thử

Mở `index.html` trong trình duyệt và thu nhỏ cửa sổ để kiểm tra bố cục desktop/mobile.
